# Tauri 源码开发模式

源码模式让真实 Tauri 窗口加载当前仓库的 Python 和 Vite 前端，省去日常修改后的发布打包步骤。安装及完整参数见[开发指南](../../../packaging/desktop/DEVELOPMENT.md)。

## 启动与验证

首次准备 Python 可编辑安装、前端依赖及平台所需的 Rust 工具链，然后在仓库根目录运行：

```sh
python scripts/dev_desktop.py --check
python scripts/dev_desktop.py
```

| 修改内容 | 验证方式 |
| --- | --- |
| Vue、JavaScript、CSS | 保存后由 Vite 热更新，必要时刷新页面 |
| Python | 保存后在“设置 → 桌面应用”或托盘中重启后端 |
| Rust | 保存后由 Tauri 自动重新编译并启动 |

首次启动仍需下载依赖并编译 Rust。Python 不自动热重载；后端重启可能中断正在执行的任务。

## 做法

- 小型 Python 入口检查解释器确实加载当前仓库，向官方 `tauri dev` 传递统一配置。
- Tauri CLI 启动 Vite 并监听 Rust；现有 Backend 管理器继续负责 Python 的启动、重启和退出。
- Vite 提供页面，将 API、聊天 WebSocket 和启动握手请求代理到本机 Python，保留现有认证及来源检查。
- 后端重启后，主窗口完成新一轮握手及受保护 API 请求，再恢复会话窗口。旧的就绪回报不能触发新一轮恢复。
- Vite 和开发外壳同时检查启动入口是否仍在运行，补齐 CLI 异常退出时的清理。

## 边界

- 默认仅绑定本机 `127.0.0.1`，使用端口 `15173` 和 `18001`。端口占用直接报错；可显式换端口，不接管已有服务。
- Python 数据默认放在 `.internal/desktop-dev`；独立的应用身份隔离外壳设置和 WebView 存储。不会自动复制安装版凭据。
- 开发模式禁用安装版更新、运行时修复、开机启动、资源管理器关联、终端命令安装及系统钥匙串管理；界面和处理入口均执行限制。
- 正常关闭窗口会退出；若启用了“关闭到托盘”，应使用托盘退出或终端 Ctrl+C。
- 不支持远程开发服务、多开发实例共享数据目录或运行中任务的无损迁移。
- 源码模式需要显式 `source-dev` 特性，release 构建拒绝该特性。普通构建继续使用打包运行时。
- 安装、首次解压、升级及操作系统集成仍需发布包验证；源码模式不是面向最终用户的便携发行版。
